
=======================================================
  Demo: JSON Formatting & Repair
=======================================================

[Valid JSON] ✅ Pass
  Input:  {"name": "Alice", "age": 30}
  Output: {"name": "Alice", "age": 30}
  🔧 JSON lỗi định dạng — đã tự sửa

[Markdown fences] ✅ Pass
  Input:  ```json
{"name": "Bob"}
```
  Output: {
  "name": "Bob"
}
  🔧 JSON lỗi định dạng — đã tự sửa

[Single quotes] ✅ Pass
  Input:  {'name': 'Charlie', 'score': 95}
  Output: {
  "name": "Charlie",
  "score": 95
}
  🔧 JSON lỗi định dạng — đã tự sửa

[Trailing comma] ✅ Pass
  Input:  {"key": "value",}
  Output: {
  "key": "value"
}
  🛟 Không sửa được — trả JSON dự phòng

[Truly invalid] ✅ Pass
  Input:  This is not JSON at all: ??? {]
  Output: {
  "error": "invalid_json",
  "detail": "Expecting value: line 1 column 1 (char 0)"
}
